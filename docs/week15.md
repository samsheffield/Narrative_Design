## Final Project
This is a freeform narrative assignment of your own choosing. It can be non-digital, interactive fiction, or something built in Unity/Unreal. You are welcome to revisit your first project and expand upon it in meaningful ways for this assignment. Collaboration is also welcome on this project, particularly if you want to experiment with integrating Ink with Unity.

### Project Deliverables:
The deliverables for this project are:
- Project pitch
- PDF of the outline for your game’s narrative
- Completed game uploaded to itch.io page (+ project files shared via Canvas)

### Playable prototype (Due: 12/04)
A playable prototype of your game is due for in-class playtesting with your peers in the second half of class.
